# WebFlyx

A fictional entertainment collection built as part of my journey learning Git and version control through [Boot.dev](https://www.boot.dev/).

## Overview

WebFlyx is a small repository containing movie titles, classic movie data, memorable movie quotes, and fictional promotional content.

The project serves as a practical environment for learning and applying Git concepts through hands-on exercises.

## Repository Structure

| File / Directory | Description |
|---|---|
| `titles.md` | Collection of movie titles |
| `classics.csv` | Classic movie data in CSV format |
| `quotes/` | Directory containing memorable movie quotes |
| `contents.md` | Index of the repository contents |
| `advert.md` | Fictional WebFlyx advertisement |
| `.gitignore` | Specifies files Git should ignore |

## Learning Objectives

This repository was used to practise:

- Git initialization and configuration
- Staging and committing changes
- Branching and merging
- Viewing and understanding commit history
- Resetting commits with soft and hard resets
- Working with Git remotes
- Fetching, pulling, and pushing changes
- Connecting local repositories to GitHub

## Purpose

The primary goal of WebFlyx is to develop a practical understanding of Git, version control, and repository management through hands-on exercises.
